面向 AI 产品经理、Agent 开发者、SaaS 创业者和个人开发者的自动化情报系统。 它每天聚合一线 AI builders 的最新内容，调用 OpenAI 生成中文结构化摘要，并通过飞书机器人推送到群聊。

01 / Context

产品背景

AI 产品、Agent、AI Coding、SaaS 和个人开发者生态变化很快，但高价值信息分散在 X/Twitter、 播客、官方博客等渠道中。普通开发者很难每天稳定跟踪一线 builders 的最新观点、产品发布和技术趋势。

本项目将“关注真正做产品的人，而不是信息搬运者”产品化：自动聚合 AI builders 的最新内容， 使用 LLM 提炼成中文 digest，并每天定时推送到飞书群，帮助个人开发者和 AI 产品团队快速获得可行动的行业信号。

02 / Goals

产品目标

自动化获取

每天自动获取 AI builders 的最新 feed，包括 X/Twitter、播客和官方博客。

中文摘要

使用 OpenAI 生成中文结构化 digest，不做机械翻译，突出信号和行动价值。

飞书推送

通过飞书自定义机器人 webhook 推送到群聊，支持签名和长消息分段。

定时运行

使用 GitHub Actions 在每天北京时间 10 点自动运行完整链路。

03 / Users

目标用户与痛点

目标用户
  • AI 产品经理
  • AI Coding / Agent 方向开发者
  • 独立开发者
  • SaaS 创业者
  • 关注 AI 产品趋势的技术团队
核心痛点
  • 信息源分散，阅读成本高。
  • 英文内容多，中文用户理解和筛选成本高。
  • 大量内容是噪音，缺少“信号级”提炼。
  • 很难每天固定追踪 builders 的最新动向。
  • 需要的不只是翻译，而是能启发产品和技术决策的摘要。
04 / Positioning

产品定位

一个面向 AI builders 的自动化中文情报助手。它不是新闻聚合器，也不是简单翻译工具， 而是围绕 AI Coding、Agent、SaaS、个人开发者、产品发布、技术趋势进行信息筛选、总结和行动启发的 digest 系统。

  • AI Coding
  • Agent
  • SaaS
  • 个人开发者
  • 产品发布
  • 技术趋势
05 / Requirements

功能需求

模块 说明 关键实现
Feed 准备 获取最新 X/Twitter builders 动态、播客内容、AI 公司官方博客、用户配置和摘要 prompt。 scripts/prepare-digest.js 输出统一 JSON。
中文摘要生成 调用 OpenAI API，将 feed JSON 转换为中文 Markdown digest。 scripts/summarize.js 读取 OPENAI_API_KEY。
飞书推送 通过飞书自定义机器人发送文本消息，支持签名、分段和错误处理。 scripts/deliver.js --method feishu。
每日运行 一键串联 prepare、summarize、deliver 完整链路。 scripts/run-daily.js。
定时调度 每天北京时间 10 点自动运行，并从 GitHub Secrets 注入敏感配置。 .github/workflows/daily-feishu.yml，cron 为 0 2 * * *。
摘要固定栏目
  1. 今日重点
  2. 产品信号
  3. 技术信号
  4. 值得关注的人/项目
  5. 对我的启发
  6. 原文链接
摘要风格
  • 中文输出。
  • 简洁，但保留判断和行动价值。
  • 只使用输入 JSON 中的事实和 URL。
  • 优先关注 AI coding、agent、SaaS、产品发布和技术趋势。
06 / Flow

核心流程

01 准备内容

执行 prepare-digest.js 获取最新 feed JSON。

02 生成摘要

执行 summarize.js，调用 OpenAI 生成中文 digest。

03 推送飞书

执行 deliver.js --method feishu，通过机器人推送到群聊。

04 定时运行

GitHub Actions 每天 02:00 UTC 自动触发。

cd scripts && npm install
cd ..
export OPENAI_API_KEY="your-openai-api-key"
export FEISHU_WEBHOOK_URL="your-feishu-webhook-url"
export FEISHU_SIGN_SECRET="your-feishu-sign-secret" # optional
node scripts/run-daily.js
07 / Quality

非功能需求

可靠性

任一阶段失败时输出清晰错误；飞书返回异常时中断任务，便于 GitHub Actions 暴露失败。

安全性

不在代码中硬编码 webhook、token、API key；所有敏感配置通过环境变量或 GitHub Secrets 注入。

可维护性

prepare、summarize、deliver 解耦，可单独测试和替换。

可扩展性

后续可扩展 Slack、Discord、企业微信、多语言摘要、历史 digest 存档和个性化关注主题。

08 / Metrics

成功指标

类型 指标
MVP 稳定性 每天自动推送成功率大于 95%。
效率 单次 digest 生成和推送耗时小于 3 分钟。
内容质量 每期 digest 至少提供 3 条可行动信号，并包含对应原文链接。
用户价值 用户每天阅读 AI builders 信息的时间减少 50% 以上。
